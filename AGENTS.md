# Agent instructions

This repository is a specification repository managed by
[ArchDoc](https://github.com/archdochq/archdoc).

**Before changing anything here, read `agents/working.md`.** It lists the rules that must not
be broken and points at a guide for each kind of task. `PROCESS.md` is authoritative wherever
anything disagrees with it.

This file is yours. ArchDoc creates it once and never rewrites it, so add whatever
project-specific instructions you like below. `archdoc agents` refreshes the `agents/`
directory only.

## House style

Documents follow the readable house style (`readable-style.md` in the `archdoc-spec-writing` skill), in the first
person singular: "I will …" in Decisions and "I rejected this because …" in Alternatives. Matter has one author, so
"we" would describe a team that does not exist. If contributors join, later documents may move to "we"; frozen ones
keep "I".

Readers are assumed to know PHP web development and at least one full-stack framework, such as Laravel or Symfony.
Concepts from that field are not explained and do not become glossary terms. Matter's own vocabulary is always a
glossary term, linked at its first occurrence in each section.

Nothing here is backfilled. Every document is written new, and agreed with the author section by section before it
is written.
